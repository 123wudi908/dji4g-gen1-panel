# v0.1.10 速率图表与采样验收

## 已确认的问题及修改

1. 全量刷新同步等待 inventory、AT/adapter、probe/hotspot，速率 tick 原先只在 runner 的 else 分支执行。新增可在阶段等待中推进只读速率采样的等待函数；串口及写入流程不变。
2. UI 每秒复制旧快照并盖上新的 UI 时间。新增 ControllerSnapshot.rates_sampled_at，来源为实际计数器读取后的共享 Clock。UI 仅消费新的采样时间，相同值的新样本仍保留；设备或绑定网卡改变时清空曲线。
3. Adapter 和 AT 并行，但 adapter 原先在等待 AT 后才盖时间戳。现在 worker 完成时记录时间；晚到 adapter 结果保留较新的速率基线。
4. 速率分母原先为整数秒。现在使用 u128 纳秒比例计算并限制到 u64 范围。
5. RateHistory 派生 Default 的 capacity 为 0；默认初始化现在委托容量为 60 的 new。

## 图表行为

蓝色下载实线、橙色上传虚线、轻量填充、独立峰值和真实样本提示。1 分钟按时间定位；间隔超过 2 秒、缺失值、非递增时间都会断线；None 与零流量严格区分。正常相邻样本用 420 ms 画面平移，时钟跳变直接重置。动画不修改样本数值；关闭 egui 动画时不插值。

## 回归证据

- 旧容量实现插入 600 点后仍保留 600 点，回归失败；修复后保留 60 点。
- 临时恢复原同步等待、整数秒除法、旧快照重复采样后，三个针对性测试均失败，日志在本地 implementation-rate-chart-20260927/before-*.log。随后恢复修复文件再执行完整验证。
- 新增 Fake AT 阻塞测试，验证在 AT 仍未完成时已经发布更新的网卡计数器速率；解除阻塞后旧 adapter 结果不能覆盖新基线。
- 新增 1.5 秒与 0.5 秒精度、真实时间间隔、独立缺片、过期峰值、重复/倒序时间戳、动画终点测试。
- ui_capture 新增 rate-normal / rate-burst / rate-gap / rate-zero / rate-missing / rate-empty 离屏组件场景。覆盖 800×600 的 100%/150% 与 360 像素窄布局；截图为真实 egui 绘制的模拟数据，不是实机吞吐量证据。
