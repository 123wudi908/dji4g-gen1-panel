# v0.1.12

- 收紧桌面字体、按钮、导航、卡片和留白，加载圈缩为 16；统一悬停、键盘焦点、忙碌与禁用反馈。
- 修复小窗口短信编辑和确认的布局，补齐发送、设置及其他命令的失败反馈；保留草稿和已确认的设置状态，避免晚到结果污染新的设备上下文。
- 维修确认展示完整操作参数，区分自动/静态 DNS、NDIS/ECM，并列出实际 DNS 地址及 CID/APN；参数不完整的摘要使用中性名称。
- 自动 IPv4 DNS 显式清除静态覆盖并回读验证；配置冲突时保守拒绝。DHCP 已关闭时明确禁用续租，不自动改写静态 IP。
- 修复热点只读探测提前退出和重复 WinRT 枚举的原生崩溃；热点执行前重新核对确认的精确模块身份及网卡绑定。
- 模糊超时及缺少读回证明的结果保留为“结果未知”，不因设备仍存在而报成功；网卡停用/启用前后核验同一接口，完整展示恢复结果，不自动重试写入。
- APN 空、非法或超长时显示禁用原因；写入与回读核验 CID、APN 和 IP 类型，拒绝活动或不完整上下文。
- USB 网络配置保存与模式生效分别说明：需手动重启模块后复检，当前网卡模式尚未验证；不自动重启模块。

本轮全项目测试 **1043 项通过**，69 个测试程序，默认跳过两个需显式运行的 fixture/主机回归；Clippy、格式与差异检查通过。界面检查使用真实 egui 渲染和模拟数据，交互与维修回归使用模拟端口。

真实设备仅做只读检查：模块通路的网关、公网与 DNS 查询，热点能力、状态和精确模块网卡读取，以及同线程连续八次 WinRT 初始化、枚举和释放回归。没有执行真实 USB 模式切换、DNS 改写、DHCP 续租、热点开关、APN 修改、网卡重启或设备重新枚举；模拟测试与只读结果不代表这些写操作已在实机通过。

详细验证范围见 [界面与维修检查记录](UI_AND_REPAIR_REVIEW_20260930.md)。
