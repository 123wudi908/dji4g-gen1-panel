# v0.1.14

新增：

- 软件启动时自动检查 GitHub Release，此后每隔 6 小时在后台检查一次；使用语义化版本比较，默认只接受正式版本。
- 顶部 GitHub 图标左侧显示更新下载入口。用户点击后才下载；检测失败保留已有有效提示，下载与安装期间暂停自动检测。
- 软件内异步下载更新，显示下载进度和大小。
- 使用 Release 的 `.sha256` 文件进行 SHA-256 完整性校验。
- Windows 独立 `dji4g-updater.exe`，等待 Panel 和同目录 helper 退出后安装。
- 更新完成后自动重启；新 Panel 首帧确认失败时尝试回滚并重启旧版。
- Windows 原生标题栏随深色、浅色及已解析的系统主题同步，切换主题后立即生效；不支持相应 DWM 属性时安全降级。
- Portable 程序位置与已有自启动项不一致时，主题等设置仍可保存；保留原自启动意图和路径不一致提示，不自动修改注册表。

更新检查或下载失败不会影响原有 DJI 4G Panel 的设备检测、AT、驱动、helper 或网络诊断功能。校验失败的更新包不会安装。

自动安装适用于正式 Windows x64 portable ZIP，安装前保留当前文件以支持失败回滚，不删除用户配置、日志和其他运行数据。MSIX 和开发目录不执行 portable 原地更新。MSIX 仍按原有包安装方式升级；自动检查及下载不等于支持原地安装。完整离线驱动包与 standalone 的原地升级未在本次验收，不承诺适用。

SHA-256 提供下载完整性检查，发布来源仍依赖 GitHub HTTPS 和上游仓库权限。此版本未提供断电恢复或独立的发布者数字签名。更新期间请保持进程和磁盘可用；如果恢复文件也被占用，保留的备份可用于人工恢复。

0.1.13 未包含独立 updater，需先手动安装 0.1.14 portable 才能在后续更新中使用软件内安装。


2026-10-08 最终验证范围：全项目自动化为 1,161 项通过、0 失败、5 项默认忽略；五项 Cargo 门禁、Portable 打包回归、MSIX dry-run、三组驱动模拟回归均通过。默认忽略的两项原生窗口测试另外以深浅色各两个进程复验通过，只读 WinRT 清单测试也已显式通过；另两项为上层测试实际调用的子进程夹具。Release updater 的合成 Panel/helper 交接、启动失败回滚和 helper 超时恢复通过；实际 Release Portable ZIP 与未签名 MSIX 校验通过。六小时边界使用模拟时间验证，没有实际等待六小时。
