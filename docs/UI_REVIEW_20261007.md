# 界面与代码检查（2026-10-07，v0.1.13）

## 已修复

- Windows 网络详情移至宽屏左栏图表下方；设备与 SIM 位于右栏。共享 760 点断点，窄屏按趋势、设备、网络、变化记录排列。
- IP 地址按实际文本高度分配空间，文本列不足 120 点时复制按钮置于下方；预留复制/已复制两个标签的最大宽度。前两条预览，复制仍包括全部地址。
- 标准按钮的内容对齐会继承外围 Grid/布局，字体行框也不等于可见字形范围。共享按钮保留 egui 输入、禁用和键盘行为，按字形可视范围居中绘制；覆盖概览显示/复制、地址复制及主操作。
- 统一浅灰白与蓝色的浅深色调色板，分开选中项与主操作；正文、按钮和选中文字状态通过对比度检查。
- 主题和语言原来在设备监测等待期间积压。新增独立有界设置通道，仅允许主题、语言及保存回执在诊断/速率读取等待中处理，每 20 ms 检查一次；所有设备操作仍使用原串行命令通道。
- 主题通过设置 revision 与原配置保存链持久化；旧配置默认跟随系统，非法值仍报配置错误，保存失败不会显示成功。
- 关于标题按三语模板填入应用名，消除 `{}` 残留；刷新按钮左侧新增圆形 GitHub 项目入口。图标缓存同时用于浅色和深色，点击才输出项目链接。
- 默认窗口缩小为 1100×720；紧凑窗口将概览说明放到头部下一行，保证所有操作按钮可见。
- 通用模组的短信刷新及单条读取在 Controller 拒绝；UI 关闭自动刷新并禁用模块读取、发送、删除、切换存储。生产适配器和平台层在串口打开前再次拒绝只读/未知档案。单条读取会改变已读状态，不能按无副作用查询放行。

## 验证

本地整工作区测试 1100 项通过、0 失败、2 项默认忽略。Clippy `-D warnings`、格式检查和差异检查通过。版本为 0.1.13，构建使用离线锁定依赖。

回归覆盖多帧 Grid 几何、759/760/761 点断点、0/1/2/4 地址、长 IPv6、三语及两种图表页签；检查复制全部、无地址禁止复制、复制后按钮位置稳定、文字可视中心及键盘/禁用行为。受阻 AT 夹具验证主题、语言及保存回执可在探测完成前发布，设备短信命令仍在队列等待。配置测试覆盖三种主题、旧配置、非法值、重复设置、失败和重新加载。

模拟预览使用真实 egui 无窗口渲染，覆盖原计划的宽高/DPI 场景，并追加 1100×720 默认窗口、1100×1400 完整卡片和 552×400@150% 三语浅深色场景；图片明确标为模拟数据。

此前 0.1.12 修复产物的原生只读检查确认了布局、地址复制和深色主题在正常重启后保留。用户随后要求不要操作电脑，0.1.13 不启动、不退出、不操作任何桌面窗口；本轮新增修复尚未进行原生点击或重启验收。源码、模拟测试和预览不能替代真实设备 SMS、驱动安装或维修操作验证。

两个默认忽略项：一个 helper 子进程入口夹具（由父回归调用），一个需要真实 Windows WinRT 主机的反复枚举回归。本轮没有发送或删除真实短信，没有执行设备、驱动或网络维修。
